# C.L.O.N.E.S

Een 3D-avonturenspel van Dex, met een dorpje, een uitvinder en een clonemachine.

**Spelen:** open `index.html` via een webserver, bijvoorbeeld:

```
python3 -m http.server
```

en ga naar http://localhost:8000. Op de iPad: open de speel-link in Safari en kies **Zet op beginscherm**.

Gemaakt met [Three.js](https://threejs.org) via een CDN, zonder build-stap. Zie `GAME.md` voor het idee en `AGENTS.md` voor de regels voor helpers.
